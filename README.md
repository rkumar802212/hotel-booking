# Juniper House Hotel Booking Demo

A small Python desktop application built with Tkinter. It lets you choose a sample room, enter check-in and check-out dates, select the guest count, see the estimated total, and create an in-memory booking confirmation.

## Run

Requirements: Python 3.10 or newer with Tkinter available.

```powershell
python dev\hotel_booking_app.py
```

The app uses sample room data only. Reservations exist only while the app is running; it does not connect to a booking service or process payments.
